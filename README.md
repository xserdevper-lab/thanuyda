# ใบเสนอราคางานซักผ้า — Mobile PWA

ไฟล์เว็บทั้งหมดอยู่หน้าแรกของ repository เปิดใช้ GitHub Pages แบบ branch ได้โดยไม่ต้องตั้ง workflow เอง

## ตั้งค่า GitHub Pages

ไปที่ Settings → Pages แล้วเลือก:

- Source: **Deploy from a branch**
- Branch: **main**
- Folder: **/ (root)**

กด Save และรอ GitHub Pages สร้างเว็บ เปิด URL ที่แสดงในหน้า Pages

เว็บไซต์ของ repository นี้จะใช้ https://xserdevper-lab.github.io/thanuyda/ เมื่อเปิด Pages และเผยแพร่สำเร็จแล้ว

## ติดตั้งลงมือถือ

- Android: เปิด URL เว็บไซต์ใน Chrome แล้วแตะติดตั้งแอป หรือเมนู ⋮ → ติดตั้งแอป / เพิ่มไปยังหน้าจอหลัก
- iPhone: เปิด URL เว็บไซต์ใน Safari → แชร์ → เพิ่มไปยังหน้าจอโฮม

ติดตั้งจากเว็บไซต์ HTTPS ที่เผยแพร่แล้ว ไม่ใช่หน้ารายการไฟล์บน github.com แอปจะเปิดเป็นหน้าต่าง standalone มีไอคอนบนหน้าจอหลัก หลังเปิดออนไลน์ครั้งแรกและเก็บไฟล์สำเร็จ สามารถเปิดออฟไลน์เพื่อคำนวณและสร้าง PDF ได้

## ฟังก์ชัน

- หน้าแรกรวมเมนูและโปรไฟล์บริษัท พร้อมเมนูติดขอบล่าง
- กำหนดรายการใบแจ้งหนี้: แก้ไขราคาซักผ้าและเพิ่มรายการ
- ตั้งค่าบริษัท: ชื่อร้าน ที่อยู่ โทรศัพท์ ทะเบียน และผู้ลงนาม
- เลือกจำนวนรายการ คำนวณยอด และตรวจสอบผ่าน Modal ก่อนยืนยัน
- สร้างใบเสนอราคา A4 และดาวน์โหลด PDF ภาษาไทย ตามโครงสร้างภาพอ้างอิง
- ประวัติใบเสนอราคา ดาวน์โหลดซ้ำได้

รายการเริ่มต้น 8 รายการ: ผ้าปูที่นอน 1.31, ผ้าขนหนูใหญ่ 1.64, ปลอกหมอน 0.82, ชุดเสื้อและกางเกง 2.95, ผ้าขนหนูเล็ก 0.49, ผ้าประคบ 0.66, ผ้าลายไทย 0.98 และผ้าคาดเตียง 1.15 บาทต่อชิ้น รวม 10.00 บาท เมื่อซักอย่างละ 200 ชิ้นต่อวัน × 30 วัน เท่ากับ 60,000 บาทต่อเดือน รุ่นนี้แทนที่รายการเดิมครั้งเดียวโดยเก็บข้อมูลบริษัทและประวัติใบเสนอราคาไว้ คำนวณด้วยจำนวนสตางค์ ไม่มี VAT เพิ่มอัตโนมัติ

ข้อมูลบันทึกใน localStorage ของเบราว์เซอร์แต่ละเครื่อง ไม่ซิงก์ข้ามเครื่อง และอาจหายเมื่อผู้ใช้ล้างข้อมูลเว็บไซต์ ควรดาวน์โหลดเอกสารเก็บไว้ ราคาที่แก้ในแอปไม่ได้แก้ซอร์สบน GitHub

PDF ใช้ภาพความละเอียด 1240 × 1754 ต่อหน้า จึงไม่สามารถเลือกข้อความได้ จัดโครงใหม่จากภาพถ่ายตามตำแหน่งหัวบริษัท ตาราง ยอดรวม ลายเซ็นและเงื่อนไข รองรับหลายหน้าเกิน 14 รายการ ตรวจการสะกดชื่อร้านและผู้ลงนามก่อนใช้จริง

## เปิดในเครื่อง

```sh
python3 -m http.server 4173
```

เปิด http://localhost:4173 ไม่เปิด index.html ผ่าน file:// เพราะใช้ JavaScript modules และ Service Worker

## ไฟล์

- index.html / style.css / app.js: หน้าจอและการทำงาน
- pdf.js: สร้าง PDF และยอดเงินตัวอักษรไทย
- manifest.webmanifest: ชื่อแอป ขอบเขต URL และไอคอนติดตั้ง
- install.js: ติดตั้ง PWA และคำแนะนำ iPhone/Android
- sw.js: เก็บไฟล์เว็บและรองรับออฟไลน์
- assets/: ฟอนต์ Sarabun ตามสัญญาอนุญาต OFL และไอคอนแอป
- .nojekyll: เผยแพร่ไฟล์ static โดยตรง

หากเปลี่ยนรายการไฟล์หรือรุ่นแอป ให้เพิ่มหมายเลข CACHE ใน sw.js และเวอร์ชัน URL ใน index.html / รายการ ASSETS ให้ตรงกัน
