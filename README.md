# เว็บแอปใบเสนอราคางานซักผ้า

แอปภาษาไทยออกแบบสำหรับมือถือ มีเมนูติดขอบล่าง และไอคอนเส้นสีน้ำเงินในวงกลมตามภาพตัวอย่าง

## ใช้งาน

1. ตั้งค่าบริษัท: ตรวจชื่อร้าน ที่อยู่ โทรศัพท์ ทะเบียน และผู้ลงนามที่ถอดจากภาพที่ 2
2. กำหนดรายการใบแจ้งหนี้: บันทึกราคาต่อหน่วย และเพิ่มรายการได้
3. สร้างใบเสนอราคา: เลือกจำนวนผ้า ตรวจยอดใน Modal แล้วกดยืนยัน
4. เติมเลขที่ วันที่ ลูกค้า เงื่อนไข แล้วบันทึกและดาวน์โหลด PDF
5. หน้าแรกแสดงเอกสารล่าสุด สามารถดาวน์โหลดซ้ำได้

ผ้าขนหนูเล็ก/ใหญ่เริ่มต้นที่ 20 บาทต่อชิ้น รายการอื่นเริ่มต้นที่ 0 บาทและต้องกำหนดราคาก่อนออกเอกสาร ไม่มี VAT เพิ่มอัตโนมัติ จำนวนต้องเป็นจำนวนเต็ม คำนวณเงินเป็นจำนวนสตางค์เพื่อหลีกเลี่ยงการปัดเศษผิด

ข้อมูลเก็บใน localStorage ของเบราว์เซอร์เครื่องนั้น ไม่ซิงก์ข้ามเครื่อง และจะหายเมื่อล้างข้อมูลเว็บไซต์ ดาวน์โหลด PDF เก็บไว้ด้วย

## นำขึ้น GitHub Pages

1. สร้าง repository แล้วนำไฟล์ในโฟลเดอร์นี้ขึ้น branch `main` รวม `dist` และ `.github/workflows/pages.yml`
2. ไปที่ Settings → Pages → Build and deployment → Source เลือก GitHub Actions
3. เปิด Actions และรอ workflow Deploy GitHub Pages สำเร็จ
4. เปิด URL ที่แสดงใน Settings → Pages

ไฟล์เว็บไซต์อยู่ใน `dist/` ทั้งหมด ใช้ HTML, CSS, JavaScript ไม่ต้องติดตั้ง npm และไม่มีบริการภายนอกหรือ API key

## เปิดทดสอบในเครื่อง

ต้องเปิดผ่าน HTTP server เพื่อโหลด JavaScript modules:

```sh
python3 -m http.server 4173 --directory dist
```

จากนั้นเปิด http://localhost:4173

## โครงสร้าง

- `dist/index.html`: หน้าเว็บหลัก
- `dist/style.css`: หน้าจอมือถือ ไอคอน และเมนูติดขอบล่าง
- `dist/app.js`: เมนู รายการ ราคา บริษัท Modal เอกสาร และการบันทึกข้อมูล
- `dist/pdf.js`: ตัวอักษรยอดเงินภาษาไทย ตัวอย่าง A4 และดาวน์โหลด PDF
- `dist/assets/Sarabun-Regular.ttf`: ฟอนต์ Sarabun แบบ OFL ใช้ในเว็บและเอกสาร
- `.github/workflows/pages.yml`: เผยแพร่ GitHub Pages จากโฟลเดอร์ dist

PDF ใช้ภาพความละเอียด 1240 × 1754 ต่อหน้าเพื่อรักษาฟอนต์ไทยและตำแหน่งตาราง จึงไม่ใช่ PDF ที่เลือกข้อความได้ รองรับหลายหน้าเมื่อเกิน 14 รายการ โครงสร้างยึดภาพที่ 2 แต่ฟอนต์และระยะต่าง ๆ เป็นการสร้างขึ้นใหม่จากภาพถ่าย ไม่ใช่สำเนาต้นฉบับทุกพิกเซล

## การตรวจสอบ

ตรวจ syntax ของ JavaScript และทดสอบในเบราว์เซอร์จริง: เลือกผ้าขนหนู 2 + 3 ชิ้น × 20 บาท ได้ 100 บาทใน Modal ดาวน์โหลด PDF ได้จริง ตรวจ A4 หนึ่งหน้าและตัวอักษรไทยผ่านภาพเอกสารแล้ว
