# ใบเสนอราคางานซักผ้า — Mobile PWA

เว็บภาษาไทยสำหรับมือถือ พร้อมเมนูติดขอบล่าง ตั้งค่าบริษัท กำหนดราคาต่อชิ้น เลือกจำนวน ตรวจรายการผ่าน Modal สร้างใบเสนอราคา PDF A4 และดาวน์โหลดประวัติเอกสาร

## ราคาที่ตกลงใช้

| ผ้าคลุมโต๊ะ (สีทอง) | 8.00 |
| ปลอกคลุมพนักพิง | 6.00 |

| ผ้าห่ม (แบบบาง) | 15.00 |

รายการ 1–8 รวม 11.00 บาท/เซ็ต เมื่อคิด 200 เซ็ต/วัน × 30 วัน = 66,000 บาท/เดือน รายการ 9–14 อย่างละ 1 ชิ้น/วัน × 30 วัน = 1,950 บาท/เดือน รวม 67,950 บาท/เดือน หรือ 815,400 บาท/ปี ไม่มีการเพิ่มยอดปรับให้ครบ 750,000 บาท

หน้าเลือกจำนวนคำนวณจากจำนวนชิ้นที่กรอกจริง ไม่คูณจำนวนวันหรือจำนวนเซ็ตอัตโนมัติ หากออกใบเสนอราคารายเดือนตามจำนวนข้างต้น ให้กรอกรายการ 1–8 อย่างละ 6,000 ชิ้น และรายการ 9–14 อย่างละ 30 ชิ้น

ราคาใหม่จะอัปเดตรายการ 1–8 ในเบราว์เซอร์เดิมครั้งเดียว พร้อมเก็บข้อมูลบริษัท ประวัติเอกสาร และรายการเพิ่มเติมไว้ หลังอัปเดตแล้วยังแก้ราคาเองได้

## GitHub Pages

Settings → Pages → Source: **Deploy from a branch** → Branch: **main** → Folder: **/ (root)** → Save

เว็บไซต์: https://xserdevper-lab.github.io/thanuyda/

ไฟล์เว็บอยู่หน้าแรกของ repository ไม่ต้องติดตั้ง npm

## ติดตั้งบนมือถือ

- Android: เปิดเว็บใน Chrome → เมนู ⋮ → ติดตั้งแอป / เพิ่มไปยังหน้าจอหลัก
- iPhone: เปิดเว็บใน Safari → แชร์ → เพิ่มไปยังหน้าจอโฮม

เปิดออนไลน์ครั้งแรกเพื่อให้ Service Worker เก็บไฟล์สำหรับใช้ออฟไลน์ ข้อมูลเก็บใน localStorage แยกตามเครื่องและเบราว์เซอร์ ไม่ซิงก์ข้ามเครื่อง อาจหายเมื่อล้างข้อมูลเว็บไซต์ ควรดาวน์โหลด PDF เก็บไว้

## ทดสอบในเครื่อง

```sh
python3 -m http.server 4173
```

เปิด http://localhost:4173 ผ่าน HTTP ไม่เปิดด้วย file://

## PDF และไฟล์

PDF ใช้ภาพความละเอียด 1240 × 1754 ต่อหน้า รักษาฟอนต์ไทยและโครงสร้างตามภาพอ้างอิง แต่ไม่สามารถเลือกข้อความได้ รองรับหลายหน้าเมื่อเกิน 14 รายการ ข้อมูลบริษัทเริ่มต้นถอดจากภาพที่ให้มา สามารถแก้ไขในหน้าตั้งค่าบริษัทได้

index.html / app.js / style.css เป็นส่วนหน้าจอและการคำนวณ, pdf.js สร้าง PDF, manifest.webmanifest และ install.js ใช้ติดตั้งแอป, sw.js รองรับออฟไลน์, assets เก็บไอคอนและฟอนต์ Sarabun พร้อม OFL, .nojekyll ใช้เผยแพร่ไฟล์ static โดยตรง
